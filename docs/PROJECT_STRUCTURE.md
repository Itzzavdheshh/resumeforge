## Key Directories

### `app/`

The Next.js App Router source directory. Following Next.js conventions:
- Directories map to URL routes
- `layout.tsx` files define shared UI for their subtree
- `page.tsx` files are route endpoints
- Files in `api/` subdirectories named `route.ts` define API endpoints

### `app/api/compile/`

The only API endpoint. `route.ts` exports a `POST` handler that compiles LaTeX.

### `docs/`

Project documentation directory created in Prompt 1. Contains all project memory files. Not served by Next.js — these are internal developer/AI documentation only.

### `public/`

Static files served directly by Next.js at the root URL. Currently contains only default Next.js placeholder SVGs. Future: could contain ResumeForge logo, favicon variants, etc.
